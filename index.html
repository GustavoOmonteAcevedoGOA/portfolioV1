AI-Augmented Development

The biggest change in these last five years: AI became part of how I build software every day. I'm currently a member of the AI Integration team on a multi-tenant construction ERP SaaS platform (C# / .NET, React / TypeScript, Azure), building the platform's AI assistant.

What I build with AI

  • MCP (Model Context Protocol) tools: typed, deterministic, unit-tested endpoints over the payroll / HR domain, wired into an LLM-powered chat engine (OpenAI API, streaming-first SSE architecture with tool-lifecycle events).
  • AI-assisted delivery workflow: Claude Code for investigation, root-cause analysis and implementation, with every PR reviewed by humans plus automated AI code review.
  • Validation of financial calculations and bug fixes against real tenant data with Playwright browser automation before QA handoff.

Principles I work by

  • AI accelerates the work, but I own correctness: every AI-assisted change ships with tests and human review.
  • Give models typed, deterministic, well-tested tools instead of free-form access to systems.
  • Validate output against real data — a plausible-looking answer is not a correct one.
  • Context is leverage: I write investigation docs and diagnostic scripts into the repo, so root-cause knowledge survives beyond each ticket, for humans and AI alike.
